# Projeto de Consultoria 

## 📌 Sobre o projeto

Este repositório contém os códigos, análises e resultados desenvolvidos no projeto da disciplina de **Consultoria**, realizado na Universidade Estadual de Campinas (UNICAMP).

O projeto tem como objetivo utilizar técnicas de **programação, análise exploratória de dados e estatística** para auxiliar na investigação de um problema real de pesquisa, transformando os dados coletados em informações relevantes para o desenvolvimento do estudo.

Ao longo do projeto serão desenvolvidas rotinas para **limpeza, organização, exploração e análise dos dados**, além da construção de análises estatísticas e visualizações em Python.
